# AutoDevGraph

An agentic workflow that autonomously designs and writes a production-ready FastAPI backend from a plain-English project description. Built with [LangGraph](https://github.com/langchain-ai/langgraph) and powered by OpenAI.

## How It Works

The workflow is a directed graph of three specialized AI agents that collaborate in a loop until the generated code passes validation:

```
Architect ──► Developer ◄──► write_files (tool)
                  │
                  ▼
               Tester
                  │
          ┌───────┴───────┐
        PASS            FAIL → Developer (retry, max 3)
          │
         END
```

1. **Architect** — Reads the task description and outputs a structured `TechnicalSpec`: ORM models, endpoints, Pydantic schemas, validation rules, business constraints, and the exact file list to generate.

2. **Developer** — Receives the spec (and any error feedback from the tester) and writes complete, production-grade Python files to disk using the `write_to_disk` tool. Follows a ReAct loop — it keeps calling the tool until every file is written, then emits a plain summary to signal completion.

3. **Tester** — Runs validation against the generated files. If errors are found they are fed back to the Developer for a targeted fix. The loop repeats up to three times; if all tests pass the graph terminates.

### Generated File Structure

Every run produces a self-contained FastAPI application under `backend/`:

```
backend/
├── database.py      # SQLAlchemy engine, SessionLocal, Base, get_db
├── models.py        # ORM models
├── schemas.py       # Pydantic request/response schemas
├── auth_utils.py    # bcrypt hashing, JWT creation, OAuth2 dependency
├── routers/
│   ├── auth.py      # POST /auth/register, POST /auth/login
│   ├── user.py      # GET/PUT /user/profile, social links
│   └── project.py   # POST/PUT /project, POST /project/slides, GET /view/{link}
└── main.py          # FastAPI app factory
```

## Tech Stack

| Layer | Library |
|---|---|
| Workflow orchestration | `langgraph` |
| LLM integration | `langchain`, `langchain-openai` |
| LLM | OpenAI `gpt-4o-mini` (swappable to Claude) |
| Generated API framework | FastAPI |
| Generated ORM | SQLAlchemy (SQLite) |
| Generated auth | `passlib[bcrypt]`, `python-jose` (HS256 JWT) |

## Prerequisites

- Python ≥ 3.11
- [uv](https://github.com/astral-sh/uv) (recommended) or pip
- An OpenAI API key

## Setup

```bash
# 1. Clone the repo
git clone https://github.com/your-username/AutoDevGraph.git
cd AutoDevGraph

# 2. Install dependencies
uv sync

# 3. Configure environment variables
cp .env.example .env
# Edit .env and add your keys:
#   OPENAI_API_KEY=sk-...
#   SECRET_KEY=your-jwt-secret
```

## Running the Workflow

```bash
uv run python main.py
```

The workflow streams each node's output to stdout as it runs. When it finishes, the complete FastAPI application is written to the `backend/` directory.

To run the generated API:

```bash
uv run uvicorn backend.main:app --reload
```

The interactive API docs are then available at `http://localhost:8000/docs`.

## Customising the Task

Edit the `user_task` string at the bottom of `main.py` to describe any FastAPI project. The Architect agent will derive all models, endpoints, and business rules from your description.

```python
# main.py
user_task = """
Describe your project here. Be as detailed as you like — the Architect
will turn it into a concrete technical specification for the Developer.
"""
```

## Swapping the LLM

The active model is `gpt-4o-mini`. To switch to Anthropic Claude, uncomment the `ChatAnthropic` block in `main.py` and set `ANTROPIC_API_KEY` in your `.env`:

```python
from langchain_anthropic import ChatAnthropic

llm = ChatAnthropic(
    model="claude-3-5-sonnet-20240620",
    temperature=0,
    anthropic_api_key=os.getenv("ANTROPIC_API_KEY"),
)
```

## Project Structure

```
AutoDevGraph/
├── main.py           # Entry point — builds the graph and streams the task
├── graph.py          # LangGraph workflow definition and edge routing
├── config.py         # LLM initialisation (model, API key, temperature)
├── state.py          # AgentState TypedDict and TechnicalSpec schema
├── agents/
│   ├── architect.py  # Architect node — produces the TechnicalSpec
│   ├── developer.py  # Developer node — writes files via tools
│   └── tester.py     # Tester node — validates output, returns errors or PASS
├── tools/
│   ├── file_system.py   # write_to_disk tool
│   └── dependencies.py  # shared tool list exported as all_tools
├── backend/          # FastAPI application (generated by the workflow)
├── pyproject.toml
├── uv.lock
└── .env
```
